# Teaching Plan

| Week | Practical | Focus |
| --- | --- | --- |
| 1 | Flutter Setup | Prepare and verify the Flutter development environment |
| 2 | Hello World | Create and run a minimal Flutter application |
| 3 | Common Widgets | Compose interfaces with commonly used widgets |
| 4 | Interactive Forms | Build and validate interactive forms |
| 5 | Layout Widgets | Arrange responsive interfaces with layout widgets |
| 6 | Icons, Images, and Charts | Present visual assets and charted data |
| 7 | Navigation and Gestures | Connect screens and respond to user gestures |
| 8 | Files, Libraries, and JSON | Work with packages, files, and structured data |
| 9 | Firebase Integration | Connect an application to Firebase services |
| 10 | Testing and Deployment | Test an application and prepare a deployment |
| 11 | Mini Project | Apply course concepts in a small independent project |

Each practical is intended to be implemented in its own weekly directory.
